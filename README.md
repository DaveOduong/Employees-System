# Employee Management System

## Description
A web-based Employee Management System developed using HTML, CSS, JavaScript, PHP and MySQL. It allows users to register, view, update and delete employee records.

## Technologies Used
- HTML – Creates the employee registration form.
- CSS – Styles the form and improves its appearance.
- JavaScript – Validates user input before submission.
- PHP – Handles database operations and CRUD functionality.
- MySQL – Stores employee information.

## Features
1. Register new employees.
2. Validate required fields.
3. Check email address format.
4. View registered employees.
5. Update employee information.
6. Delete employee records.
7. Clear the registration form.

## Database Structure

**Database Name:** `company_db`

**Table Name:** `employees`

| Field | Description |
|---|---|
| id | Employee ID (Primary Key) |
| employee_name | Full Name |
| national_id | National ID |
| phone_number | Phone Number |
| email | Email Address |
| department | Department |

## Installation and Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Create a database named `company_db` using phpMyAdmin.
4. Create the `employees` table.
5. Copy the project folder into the `htdocs` directory.
6. Configure the PHP database connection.
7. Open your browser and visit:

   `http://localhost/EmployeeManagementSystem/`

## CRUD Operations

- **Create:** Add new employee records.
- **Read:** Display existing employee records.
- **Update:** Edit employee information.
- **Delete:** Remove employee records.

## Project Objective
To develop a simple web-based system that demonstrates form creation, input validation, database connectivity and CRUD operations using PHP and MySQL.
